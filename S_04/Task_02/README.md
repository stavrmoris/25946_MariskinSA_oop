# Задания 4.I и 4.II

Бинарная операция для домашнего задания — поиск значения с максимальным модулем
через `std::accumulate` с сохранением знака числа
При равных модулях выбирается первое встретившееся значение

## Исходные файлы

Положите рядом с `main.cpp` два файла из Classroom:

- [s04_v1_46_1.txt](https://drive.google.com/file/d/1V8mPGxWR_Ro7hrBwuDQPOavmxcijhk1h/view)
- [s04_v1_46_2.txt](https://drive.google.com/file/d/1En4d-HwGJzmxKuFeRdIQAM7ZdbwKBabr/view)

Файлы с числами исключены из Git согласно правилам оформления репозитория
После клонирования их нужно скачать отдельно
Программа поддерживает разделение чисел пробелами, переносами строк и запятыми
Запись `89-56` в первом файле читается как два числа: `89` и `-56`

## Что делает программа

1. Читает числа типа `int` в два вектора и считает их размеры
   Первым становится вектор с большим количеством элементов
   При одинаковых размерах сохраняется порядок файлов
2. Считает частоты каждого числа через `for` и `std::for_each`
3. Считает полные суммы через `std::accumulate` и `std::for_each`
4. Считает суммы первых 10 элементов через `std::accumulate` без явного цикла
5. Находит максимальное по модулю значение через `std::accumulate`
6. Выводит числа с частотой от 2 во втором векторе и от 4 в первом
7. Находит числа, удовлетворяющие обоим ограничениям, через `for`
   и через `std::copy_if` с лямбдой, выводит обе частоты

Суммы и модули вычисляются в `long long`, сами элементы хранятся как `int`
Если чисел меньше 10 или вектор пуст, программа сообщает о недоступной операции
Результаты выводятся в консоль

## Windows

Откройте Developer PowerShell for VS и перейдите в папку задания

```powershell
chcp 65001
cl /nologo /std:c++17 /W4 /EHsc /utf-8 main.cpp /Fe:task_02.exe
.\task_02.exe
```

Можно передать пути к другим файлам, заключив пути с пробелами в кавычки:

```powershell
.\task_02.exe "C:\Data\first.txt" "C:\Data\second.txt"
```

## macOS и Linux

Из папки задания:

```sh
c++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o task_02
./task_02
```
