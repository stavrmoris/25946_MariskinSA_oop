# Домашнее задание 3.IV

Индивидуальный вариант из Classroom задан в `config.h`: `T1 = double`,
`T2 = int`, `M = 14`, `N = 2`.

Программа создаёт `array`, `vector`, `list` и `deque`, заполняет их случайными значениями из `[-N, N]`, один раз выбирает общий второй аргумент, применяет `modified::average<T2>` и переносит результаты в контейнеры других видов. Использованы индексный, итераторный и range-based циклы. Таблица из `M` строк записывается в `results.md`.

## Запуск на Windows через cl

Нужен компилятор MSVC из Visual Studio или Build Tools с компонентом
«Разработка классических приложений на C++»

1. Откройте **Developer PowerShell for VS**
2. Перейдите в корень скачанного или склонированного репозитория, затем в папку задания:

```powershell
cd S_03\Task_04
```

3. Включите UTF-8 для русских сообщений и соберите программу:

```powershell
chcp 65001
[Console]::OutputEncoding = [System.Text.UTF8Encoding]::new()
cl /nologo /std:c++17 /W4 /EHsc /utf-8 main.cpp /Fe:task_04.exe
```

4. После успешной сборки запустите:

```powershell
.\task_04.exe
```

В PowerShell для запуска из текущей папки нужен префикс `.\`
Если команда `cl` не найдена, используйте Developer PowerShell for VS
с установленным компонентом C++, чтобы окружение компилятора было настроено

## Запуск на macOS и Linux

Из корня репозитория перейдите в папку задания:

```sh
cd S_03/Task_04
```

Соберите и запустите программу:

```sh
c++ -std=c++17 -Wall -Wextra -Werror -pedantic main.cpp -o task_04
./task_04
```
